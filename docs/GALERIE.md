# CSV-Auswertung – Ergebnisse

Die Grafik zeigt die Effizienzspannen der 16 Standorte aus der mitgelieferten CSV. Sie verwendet die Werte aus einem Lauf des unveränderten Java-Programms und ordnet sie wie dessen MergeSort-Ausgabe absteigend an.

![Effizienzspanne je Produktionsstandort](media/01-effizienzspanne.png)

Das Programm gibt zu jedem Standort zusätzlich Minimum, Maximum und durchschnittlichen Gewinn aus. Die [vollständige Ergebnistabelle](PROJEKT.md#mitgelieferte-daten) enthält diese Werte.
